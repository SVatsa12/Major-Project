# Social Media Privacy Policy Compliance Auditor (India Data Governance)

An end-to-end Natural Language Processing and Machine Learning pipeline designed to audit social media terms of service and privacy policies against statutory Indian data governance mandates:
* **Digital Personal Data Protection Act, 2023 (DPDPA)**
* **Digital Personal Data Protection Rules, 2025 (DPDPR)**
* **Information Technology Act, 2000 & Intermediary Guidelines (IT Act)**

The system parses unstructured corporate policies, filters out non-privacy clauses, matches policy text to a 30-rule regulatory taxonomy, classifies compliance status across a three-tier spectrum (`Compliant`, `Partially Compliant`, `Not Addressed`), and generates an empirical compliance scorecard for audited platforms (Google, WhatsApp, Telegram, Meta, Snapchat, YouTube).
